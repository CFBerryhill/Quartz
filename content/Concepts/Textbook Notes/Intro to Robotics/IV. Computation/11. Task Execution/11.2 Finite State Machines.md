A finite state machine is defined as a Tuple $(\Sigma, S, s_{0},\delta, F)$ where:
- $\Sigma$ is the input Alphabet, the set of symbols that represent events that can trigger state transitions.
- $S$ is a finite set of states
- $s_0$ is an initial state and an element of $S$
- $\delta$ is the state transition function $\delta : S\times\Sigma \rightarrow S$
- $F$ is the set of final states, a subset of $S$
